# Выбор Java Spring Boot и Thymeleaf для приложения

## Контекст и постановка задачи
Для проекта «LeafLog» нужно создать безопасное веб-приложение с авторизацией, базой данных и серверным рендерингом страниц. SRS фиксирует Java 21 и Thymeleaf (`REQ-INT-009`).

## Драйверы решения
* Безопасность (хэширование паролей, защита от CSRF, изоляция данных пользователей, `REQ-SEC-002`, `REQ-SEC-003`).
* Скорость разработки (команда Senior + Junior, жёсткий срок).
* Единый деплой на один сервер (`REQ-DIST-001`).

## Рассмотренные варианты
* Java + Spring Boot + Thymeleaf
* Java + Spring Boot + React (SPA)
* Python + Django

## Итог решения
Выбран вариант **«Java + Spring Boot + Thymeleaf»**, так как он закрывает требования безопасности встроенными средствами и даёт один артефакт для развёртывания.

### Последствия
* **Хорошо**, потому что Spring Security и Spring Data JPA покрывают безопасность и работу с БД, а приложение собирается в один JAR.
* **Плохо**, потому что интерфейс менее интерактивен, чем SPA: страницы перезагружаются.

### Подтверждение
Проверка через код-ревью и автотесты безопасности (пользователь не имеет доступа к чужим растениям).

## Плюсы и минусы вариантов

### Java + Spring Boot + Thymeleaf
* Хорошо, потому что простая архитектура и готовые модули безопасности.
* Плохо, потому что меньше интерактивности на клиенте.

### Java + Spring Boot + React (SPA)
* Хорошо, потому что богатый интерфейс.
* Плохо, потому что две кодовые базы и отдельное REST API, что дольше в разработке.

### Python + Django
* Хорошо, потому что быстрая разработка.
* Плохо, потому что противоречит заданному SRS стеку.

## Дополнительная информация
* Связанные требования SRS: `REQ-INT-009`, `REQ-SEC-002`, `REQ-SEC-003`.
* Связанные элементы SDD: `002-composition`, `003-structure`.
