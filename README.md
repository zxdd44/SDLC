# Конвертер веса (вариант №5)

Бухвал Павел, группа 450504
**Дисциплина**: Жизненный цикл разработки программного обеспечения
**Описание**: данный проект позволяет перевести сущности из одной единицы в другую. Пользователь вводит количество, выбирает сущность (например, цыплёнок) и выбирает какую сущность он хочет сопоставить первоначальному варианту.
