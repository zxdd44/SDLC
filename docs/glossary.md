# Глоссарий проекта «LeafLog»

Настоящий документ содержит определения основных терминов предметной области, ролей пользователей и технических понятий, используемых в проектной документации и при разработке веб-приложения «LeafLog».

| Термин | Определение |
| :--- | :--- |
| **LeafLog** | Веб-приложение для ведения личной коллекции комнатных растений, автоматического планирования ухода и хранения дневника наблюдений с фотографиями. |
| **Пользователь (User)** | Зарегистрированный и авторизованный цветовод-любитель, ведущий свою коллекцию растений (от 3 до 50 экземпляров), график ухода и дневник наблюдений. |
| **Гость (Guest)** | Неавторизованный посетитель веб-приложения, которому доступен только просмотр публичного справочника видов растений, регистрация и вход в систему. |
| **Администратор (Administrator)** | Сотрудник поддержки, управляющий справочником видов растений и имеющий доступ к журналу действий (функционал отложен в релиз 2.0 со статусом *Deferred*). |
| **Растение (Plant)** | Конкретный экземпляр комнатного растения в личной коллекции пользователя, имеющий индивидуальное имя, привязку к биологическому виду и личную историю ухода. |
| **Вид растения (Species)** | Справочная единица из открытого внешнего API, содержащая ботаническое название и базовые параметры ухода (рекомендуемые интервалы полива, подкормки и требования к освещению). |
| **Локальный кэш справочника** | Таблица `Species` в базе данных PostgreSQL, в которой сохраняются загруженные из внешнего API данные о видах для обеспечения автономной работы при сбоях внешнего сервиса (`REQ-REL-002`). |
| **Задача ухода (Care Task)** | Запланированное системное или пользовательское событие по уходу за растением (полив, подкормка, пересадка), обладающее типом, плановой датой выполнения (`due_date`) и статусом. |
| **График ухода (Care Schedule)** | Последовательность задач ухода, которая формируется системой автоматически на основе интервалов выбранного вида растения и пересчитывается после каждой отметки о выполнении. |
| **Жизненный цикл задачи** | Переход задачи ухода между состояниями: `Запланирована` (срок ещё не наступил или наступил сегодня), `Просрочена` (вычисляемое состояние при пропуске плановой даты) и `Выполнена`. |
| **Дневник наблюдений (Diary)** | Хронологическая лента заметок о состоянии конкретного растения, содержащая дату, текстовое описание, тип проведённого ухода и прикреплённые фотографии. |
| **Запись дневника (Diary Entry)** | Отдельная заметка в дневнике наблюдений растения, к которой можно прикрепить изображения размером до 5 МБ (`REQ-FUNC-008`). |
| **Напоминание (Reminder)** | Автоматическое уведомление о предстоящих на сегодня или просроченных задачах по уходу, отображаемое в веб-интерфейсе и отправляемое на email пользователя. |
| **Журнал отправок (`ReminderLog`)** | Таблица в БД для фиксации статуса отправки email-напоминаний, исключающая дублирование писем и позволяющая повторно отправлять уведомления после сбоев SMTP (`REQ-REL-001`). |
| **Экспорт в PDF** | Функция генерации и скачивания структурированного PDF-документа, содержащего сводку по растению, записи дневника на русском языке и прикреплённые фотографии (`REQ-FUNC-013`). |
| **Изоляция данных** | Требование информационной безопасности (`REQ-SEC-003`), гарантирующее, что каждый авторизованный пользователь имеет доступ исключительно к своим растениям, задачам и фотографиям. |
| **Внешний API справочника** | Сторонний веб-сервис, предоставляющий структурированную информацию о видах комнатных растений по протоколу HTTP/HTTPS (`REQ-INT-007`). |
| **SMTP-сервер** | Внешний почтовый сервер, используемый модулем уведомлений для рассылки email-напоминаний пользователям (`REQ-INT-008`). |
